От списка к рабочим прокси

Настройте один раз. Возвращайтесь к проверке и результатам в этом окне.

1

Выберите сервисы

Введите URL каждого нужного сервиса. Прокси проходит отбор, только если работает со всеми. Код 200 — обычный успешный ответ; для API с другими кодами укажите свои.

Для защиты от заглушек укажите текст, который должен быть в ответе. Редиректы не выполняются: используйте конечный URL.

2

Дайте списку пройти целиком

«Найти и проверить» сначала собирает адреса, затем проверяет каждый. Список из 190 тысяч адресов может занять несколько часов. Число зависит от источников.

Остановка сохраняет завершённые результаты. Для продолжения оставьте те же сервисы, попытки и таймаут.

3

Выберите лучшие и скачайте

«По скорости» — сначала минимальная задержка. «По качеству» — баланс успешности, скорости и разброса. Укажите любое количество; 0 сохраняет все подходящие.

TXT содержит адреса, CSV — таблицу рейтинга, JSON — подробные результаты запросов.

Что важно понимать

Это оценка доступности и времени ответа, не пропускной способности в Мбит/с. Публичный прокси может перестать работать после проверки: используйте «Перепроверить» для свежих результатов.

Новые URL или параметры замеров создают отдельный профиль. Настройки и история хранятся локально. Закрытие вкладки не останавливает приложение; для выхода закройте его окно терминала через Ctrl+C.
