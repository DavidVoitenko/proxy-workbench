# Development instructions

- Work on `main` unless the user requests another branch.
- Keep Git author and committer identity `Anonymous <anonymous@example.invalid>`.
- Do not commit personal names, personal email addresses, hostnames or absolute home paths.
- Keep private configuration, proxy credentials, databases and generated results in ignored `data/`.
- Do not copy account configuration from other projects or import their Git history.
- Keep launchers and resource paths relative to this project.
- Do not run tests, proxy scans or network checks unless the user requests them.
- When tests are requested, use isolated temporary data and local mock services.
