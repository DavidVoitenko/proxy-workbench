# Проверка и объединение main — 26.09.2026

Ветки `integration/ultra-2026-09-25`, `sources-catalog`, `pr-27` и обе
удалённые рабочие ветки включены в историю `main`. Уже перенесённые изменения
сверены с исходными ветками; актуальная реализация и оформление сохранены.

## Исправления

- Каталог: все 150 исследованных записей доступны в поставке, 98 допускают
  сбор. Восстановлены CLI-команды и прежние API-маршруты, выбор источников,
  обновление, предпросмотр, метаданные, пагинация и восстановление кеша.
  Учтены `Retry-After` и backoff. Пустой пользовательский набор остаётся пустым.
- Поиск: продолжение ограничено коллекцией, профилем и ревизией доступа;
  учитываются ранее найденные адреса, страна выхода и результат проверки
  репутации. Бюджеты запросов и тела ответа применяются до сетевой операции.
- Задания: очередь действительно выполняется; API, GUI, desktop и headless
  используют общий исполнитель. Состав задания фиксируется при постановке.
  Pause/cancel останавливают измерения; продолжение сохраняет наблюдения.
- Расписания: общий исполнитель запускает календарные задания, учитывает
  перезапуск, пробуждение, питание и израсходованные бюджеты. Пулы ограничивают
  историю и не повторяют ошибочный refill непрерывно.
- Данные: импорт больших списков не удаляет сохраняемые адреса; секреты
  участвуют в транзакции импорта без промежуточных commit. Сессии одного
  хранилища используют общий vault; поставки включают `keyring`.
- Транспорт: исправлены POST/100 Continue, SOCKS4a, проверки SOCKS5,
  TLS/SOCKS для длительных соединений, WebSocket handshake/pong и границы
  чтения. Новое соединение не выдаётся за повторно используемое.
- Поставка: wheel, Docker и приложения включают каталог, OpenAPI и переводы.
  Исправлены launchers, относительные пути, `--data`, single-instance,
  Windows lock, длинные пути и перенос SQLite с WAL. Добавлена отдельная
  сборка macOS Intel.

## Проверки

Все сетевые проверки продукта используют временные данные и локальные
HTTP/TLS/SOCKS-сервисы. Публичные прокси не сканировались. Отдельно в браузере
проверены применение набора, создание коллекции, предпросмотр и импорт:
2 пригодных адреса, 1 дубликат и 1 отклонённая строка; ошибок JavaScript нет.

Основные воспроизводимые команды:

```sh
python -m unittest discover -s tests -v
python functional_acceptance.py
python packaging/verify_wheel.py dist/proxy_workbench-2.3.0-py3-none-any.whl
python packaging/smoke.py <путь-к-приложению>
python packaging/verify_delivery.py <путь-к-приложению>
```

Исследовательская фикстура сбора: 45,1 → 18,7 секунды после пакетной записи
SQLite. Это локальный замер сохранённых образцов, не скорость публичной сети.

## Границы проверки

- 150 записей каталога не означают 150 автоматически работающих лент:
  коммерческие сервисы, собственные серверы и неподдерживаемые форматы
  отображаются с причиной недоступности.
- Неподключённые индивидуальные настройки источников возвращают явную ошибку,
  а не сообщение об успешном сохранении.
- OS-vault проверяется через изолированный mock; CI и smoke не записывают
  тестовые пароли в личную системную связку ключей.
- macOS/Windows артефакты не имеют подписи издателя без соответствующих
  сертификатов. `universal2` не создаётся; Intel и ARM собираются отдельно.
