What the rotating proxy serves

A binding pins the pool and the profile the rotating proxy offers. A pinned generation means "this exact export", so publishing a new run does not move a client that is already connected.

ACCESS CONTROL

API keys

A key is the identity your own programs present to /v1. The secret is shown once, at the moment it is issued, and is never stored anywhere you can read it back from.

FIRST KEY

The first administrator key

This is the only action that needs no credential: the interface is a local, file-locked surface. Every key after this one is issued through the interface as an administrator.

SECRET

Copy the secret now — it is not shown again

The verifier stored in the database is one-way: the program cannot show this secret again, and nobody — including this page — can recover it. If you lose it, issue a new key and disable this one.

NEW KEY

Issue a key

Leave empty to act as the installation's own administrator key. Paste a key to act as that one instead; it is kept in the page's memory and is never written to a file or a log.

Rights

Nothing but a secret the programs actually need. A key with no rights answers 403 to everything — that is an empty grant, not an error.

KEYS

FAQ

Frequently Asked Questions

Everything you need to know about proxies and privacy

What is a proxy and why do I need it? ▾

A proxy acts as an intermediary between your device and the internet. Websites see the proxy's IP address instead of your real IP, allowing you to bypass regional restrictions, access blocked services, and protect your privacy.

What is the difference between HTTP and SOCKS5? ▾

HTTP/HTTPS proxies are designed for web browsers and websites. SOCKS5 handles TCP streams and DNS through the proxy. This local gateway does not implement SOCKS5 UDP ASSOCIATE, Telegram calls and games that require UDP are not supported here.

Why do free proxies stop working after some time? ▾

Public proxies are hosted on servers worldwide and can be overloaded or restarted. Proxy Workbench includes an automatic Keep-Fresh (Watch) mode that continually re-checks working proxies every few minutes in the background, keeping your pool 100% active!

How does the Local Rotating Gateway (127.0.0.1:8899) work? ▾

Instead of copying dozens of proxy addresses manually into your apps, you configure only one address: 127.0.0.1:8899. The gateway automatically routes each new connection through the best verified proxy, instantly switching if any proxy drops.

Where is my data stored and is it private? ▾

100% of your data, history, and settings are stored locally on your own computer in the data/ folder. The application is completely offline-first, has no tracking, no cloud telemetry, and sends no personal data anywhere.

What will be deleted

RETENTION

Keep only fresh measurements

Old measurements and the results that depend on them are the largest part of a long-running database. The preview counts exactly the rows the delete would remove, and the delete refuses to run when a table it would empty is still referenced.

RESTORE

Restore a database into a new folder

A restore never overwrites the folder you are working in: it writes a copy into a new, empty folder and leaves the current data exactly where it is. The copy goes through SQLite's own backup API, so a database with a write-ahead log is copied consistently.

DATA FOLDER

Move the data folder

The new folder is a copy, and a backup of the old database is written first. The old folder is never deleted by this action — that stays a separate, explicit step you take yourself.
